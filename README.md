# EMS - Employee Management System 🚀

A modern Employee Management System built with React, Vite, and Tailwind CSS. This project provides separate dashboards for Admins and Employees, allowing task management and workflow tracking in a clean and responsive interface.

## Features ✨

### Admin Dashboard

* Create and assign tasks to employees
* View all employee tasks
* Monitor task progress and status
* Manage workflow efficiently

### Employee Dashboard

* View assigned tasks
* Accept new tasks
* Mark tasks as completed
* Track failed or pending tasks

### General Features

* Responsive UI
* Local storage based data management
* Component-based architecture
* Fast performance using Vite
* Clean modern interface with Tailwind CSS

## Installation ⚙️

Clone the repository:

```bash
git clone https://github.com/your-username/ems.git
```

Go to the project directory:

```bash
cd ems
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## Available Scripts 📜
